# Calibrated Joint-Residual Detection of Replay Attacks in Networked Power Systems

Reproduction, extension, and independent hybrid-model study built on Qin, Zhang & Zhao, "Data-Based Q-Learning for Replay Attack Detection in Cyber-Physical Systems," *IEEE Trans. Ind. Cyber-Phys. Syst.*, 2025.

## Reading order

1. `SOURCE_PAPER_AUDIT.md` — full extraction of the source paper, fully/partially/missing-specified.
2. `REPRODUCTION_REPORT.md` — published vs. reproduced numbers, root-cause analysis of the gap.
3. `SOURCE_WEAKNESS_ANALYSIS.md` — ranked weaknesses driving the hybrid design.
4. `DATA_AUDIT.md` + `DATA_SPLIT_MANIFEST.csv` — the multi-testbed power-system extension and its leakage controls.
5. `MODEL_CANDIDATES.md` → `MODEL_SELECTION_REPORT.md` — 4 candidate designs, validation-only screening, final selection (PISTRD).
6. `DITHER_NECESSITY_FINDING.md` — key honest finding: the source paper's encoding mechanism remains necessary at this larger scale.
7. `ROBUSTNESS_RESULTS.md` — partial-replay-attack robustness study.
8. `BENCHMARK_WTL.csv` — final win/tie/loss statistical analysis (16 benchmarks).
9. `FINAL_MODEL_CONFIG.yaml` — the frozen configuration used for all TEST-split results.
10. `LITERATURE_NOTE.md` — novelty-verification notes.
11. `FINAL_RESEARCH_SUMMARY.md` — one-page summary of everything above.

This repository contains the method source code and reproducibility documentation only. The manuscript text, figures, and rendered tables are generated by `src/figures/*.py` from the CSVs in this repo but are not checked in here.

## Reproducing the pipeline

```bash
pip install -r requirements.txt

# 1. Reproduce the source paper's own DC-motor experiment
python src/reproduction/run_reproduction.py --n_mc 1000 --n_calib 300
python src/reproduction/make_report_table.py

# 2. Build the multi-testbed power-system dataset (IEEE 14/39/57/118-bus)
python src/pipeline/build_dataset.py

# 3. Candidate screening (validation-only, 3 seeds x 4 testbeds x 4 candidates)
python src/screening/run_screening.py --n_mc 1000 --n_calib 300
python src/screening/aggregate_screening.py

# 4. Ablation / dither-necessity / partial-replay robustness (final model)
python src/ablation/run_ablation.py
python src/ablation/dither_necessity.py
python src/robustness/partial_replay.py

# 5. Full 10+ benchmark suite against the frozen final model
python src/benchmarks/run_benchmarks.py

# 6. Statistics, figures, tables
python src/stats/wtl_analysis.py
python src/figures/make_figures.py
python src/figures/make_schematics.py
python src/figures/make_tables.py

```

## Key result

PISTRD (Physics-Informed Spatio-Temporal Residual Detector) wins all 16 benchmark comparisons on the held-out TEST split across 4 IEEE bus testbeds (macro-F1 0.984–0.998 vs. 0.51–0.75 for the best alternatives), while running 5–35x faster than every deep-learning competitor. A dedicated ablation shows this is only possible because of — not despite — the source paper's stochastic measurement-encoding mechanism, which remains essential at this much larger scale.
